Wasteland Walkers

A cooperative mech experience built with procedural level generation and tactical traversal. I helped make the generation pipeline robust and supported gameplay polish for shared control.

Wasteland Walkers is built around cooperative movement and emergent challenge, with procedural terrain complexity that keeps play sessions fresh.

  • Co-op movement
  • Procedural generation
  • Tech support
  • Gameplay polish

Project Details

Language: C++ / Blueprints
Team size: 12
Duration: 8 Weeks
Key responsibilities:
  • Level generation
  • Tech artist support
  • Gameplay integration
View project announcement

Design Goal

Create a shared control experience with enough procedural variety to keep each run engaging without overwhelming the player.

Technical Approach

I implemented a procedural environment system for hazards, cover and pathing using data-driven parameters for fast iteration.

Collaboration

I worked closely with tech artists to keep generated geometry consistent with our visual pipeline and gameplay requirements.
