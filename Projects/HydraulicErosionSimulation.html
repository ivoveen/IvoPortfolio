Hydraulic Erosion Simulation

A terrain editor prototype in C++ that models hydraulic erosion, sediment transport and terrain evolution. I built the simulation core and editor integration.

This project bridges terrain research with playable tools, providing real-time hydraulic erosion controls and believable terrain evolution.

  • Hydraulic simulation
  • Terrain editor
  • Data-driven controls
  • Research prototype

Project Details

Language: C++
Team size: Solo
Duration: 8 Weeks
Key responsibilities:
  • Simulation
  • Editor integration
  • Rendering
Read the Medium article

Simulation Approach

I modelled rainfall, flow and sediment transport to evolve terrain over time, producing natural riverbeds and erosion patterns.

Editor Integration

The editor exposes parameters for erosion strength, sediment capacity and world scale for fast designer iteration.

Learning Outcome

I learned how to structure complex simulation code for interactive tools and reuse in a rendering engine.
