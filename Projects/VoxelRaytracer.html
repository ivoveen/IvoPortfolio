3D CPU Voxel Raytracer

A custom CPU raytracer rendering voxel worlds with reflections, refractions, volumetric smoke and a demo interface. The project explores low-level rendering in C++.

This technical prototype showcases a full rendering pipeline with voxel intersection, material response and procedural atmosphere.

  • CPU raytracer
  • Voxel rendering
  • Volumetric effects
  • Demo gameplay

Project Details

Language: C++
Team size: Solo
Duration: 8 Weeks
Key responsibilities:
  • Renderer
  • Materials
  • Demo integration
View the demo announcement

Rendering Pipeline

The core engine casts rays through a voxel scene and computes lighting, shadows and volumetric light on the CPU.

Materials & Lighting

I added reflective and refractive surfaces along with volumetric smoke for atmospheric depth.

Demo Integration

The final prototype includes a playable demo to show the renderer’s capabilities in a compact experience.
